## 🔍 Technical Details

### Locator Pattern
```typescript
span.button-text:has-text("Expand All")
span.button-text:has-text("Collapse All")
```

### Smart Detection Logic
```typescript
async clickExpandAllIfPresent(): Promise<boolean> {
    const isPresent = await this.isExpandAllButtonPresent();
    if (isPresent) {
        // Click and verify
        return true;
    } else {
        console.log('ℹ Expand All button not present - no expandable content');
        return false;
    }
}
```

### Test Pattern
```typescript
const hasExpandButton = await cryptoPage.clickExpandAllIfPresent();

if (hasExpandButton) {
    // Full validation cycle
    await cryptoPage.verifyCollapseAllButtonVisible();
    await cryptoPage.verifyContentExpanded();
    await cryptoPage.clickCollapseAll();
    await cryptoPage.verifyExpandAllButtonVisible();
    console.log('✅ Test passed');
} else {
    console.log('ℹ No expandable content available');
}
```
